# 05 — Готовый план печати: Bambu PETG HF White Matte на A1 (гладкие модели)

## Про сам филамент (официальные значения)
| Параметр | Значение |
|---|---|
| Температура сопла | **230–260 °C** (дефолт профиля ≈ **255 °C**) |
| Температура стола | **60–80 °C** (обычно 65–75) на гладкой/текстурной PEI |
| Камера | не требуется (открытая рама — норм) |
| Корпус | не требуется |
| Сушка перед печатью | **65 °C, 8 ч** (Bambu: PETG HF **надо сушить**) |
| **Max volumetric speed** | дефолт ≈ **21 мм³/с**; консервативный «Generic PETG HF» ≈ 16 |
| Скорость печати | **< 300 мм/с** |
| Обдув | 0–80 % (используй ~40–60 % для поверхности/нависаний) |
| Ретракт | длина **0.8–1.4 мм**, скорость **30–60 мм/с** |
| Прочность на разрыв | **34 ± 4 МПа** (по TDS) |
| Диаметр | 1.75 мм |

**Почему «HF» (High Flow):** формула плавится/течёт быстрее — держит примерно **2–3× объёмный поток** обычного PETG при том же качестве (дефолт ~21 мм³/с против ~8–10 у обычного). Даёт реально использовать скорость/ускорение A1 без недоэкструзии.

**Матовый белый:** минерально‑наполненный матовый финиш **прячет слои и нити**, чуть абразивнее (нерж. сопло ок, закалённое не обязательно для эпизодического использования). Отлично смотрится с лёгким ironing.

**Адгезия:** PETG **агрессивно** липнет к PEI — используй **текстурную PEI** + тонкий **клей‑карандаш как разделитель** (защищает пластину). Не переусердствуй с прижатием первого слоя.

## Рекомендованный профиль (гладко, качественно)
Старт: встроенный профиль филамента **«Bambu PETG HF»** + процесс **A1 0.20 mm Quality**, затем применить:

**Филамент / температуры**
- Сопло **250–255 °C** (снизить до 240–245, если нити; ≥250, если слабое спекание)
- Стол **70 °C**, **текстурная PEI** + лёгкий клей‑разделитель
- Камера — нет; при тёплой комнате снять верх / открыть дверцу
- **Сушка: 65 °C, 8 ч**
- Max volumetric — дефолт **~21 мм³/с** (снизить до 16, если пузырит/шершавит, особенно не досушено)
- Обдув **40–50 %** (0 % первые 2–3 слоя)
- Один раз на катушку: **Flow Dynamics + Flow Ratio**

**Геометрия / качество**
- Высота слоя **0.16 мм** (0.12 для мелкой детали; 0.20 ради скорости); первый слой 0.20–0.24 мм
- Стенок (wall loops) **3**; внешняя стенка на умеренных **~100–150 мм/с** (для вида — ~120)
- Верхних слоёв **5** (≈0.8 мм); нижних **4**
- Верх/низ паттерн: **Monotonic** (лучший вид верха до ironing)
- Infill **15 %**, **Grid или Gyroid**
- Шов: **Aligned** или painted в скрытую кромку; включить **wipe**

**Скорости (в пользу качества)**
- Внешняя стенка ~**120 мм/с**; внутренние быстрее; travel/infill около дефолта, но в пределах volumetric
- Снизить скорость верхней поверхности (~150–200 или ниже) для чистого верха до ironing

**Ретракт / нити**
- Длина **0.8 мм** (до 1.2, если нити), скорость **~40 мм/с**
- Включить **wipe on retract** и **combing / avoid crossing walls**

**Ironing (ВКЛ, для гладких плоских верхов)**
- Тип **All top surfaces**; паттерн **Rectilinear**
- Flow **10 %** (к 12–15 % только при щелях; PETG бугрит при высоком)
- Line spacing **0.10 мм**; speed **~20–30 мм/с**
- Прогнать быстрый тест ironing на купоне 40×40 мм — зафиксировать flow/скорость под эту матовую катушку

**Порядок калибровок (раз на катушку):** Flow Dynamics → Flow Ratio → (опц.) Max Volumetric → Ironing flow.

**Если верх всё ещё грубый после ironing:** +1 верхний слой; проверь, что flow не недоэкструдирует; чуть медленнее ironing.

## Проверить в своём Studio/Orca
Значения **max volumetric speed (≈21 мм³/с)** и **дефолтная скорость ironing** зависят от версии профиля — свериться в реальном профиле. Остальное (зона печати, температуры, ретракт, ironing flow/spacing, сушка) стабильно по нескольким официальным источникам.
