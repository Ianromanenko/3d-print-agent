# 01 — Bambu Lab A1: устройство, характеристики, подключение

## Характеристики (полноразмерный A1)
- **Зона печати:** 256 × 256 × 256 мм.
- **Стол:** текстурированная PEI‑пластина (совместим и с гладкой PEI). Магнитная, гибкая, с подогревом.
- **Экструдер:** **директ‑драйв** (короткий путь филамента → ретракт маленький, ~0.8 мм, в отличие от Bowden 3–6 мм).
- **Сопло:** 0.4 мм из нерж. стали в комплекте; опционально 0.2 / 0.6 / 0.8 мм и закалённые. Быстросъёмный хотэнд.
- **Макс. температуры:** сопло **300 °C**, стол **100 °C**.
- **Скорость:** до **500 мм/с**, ускорение до **10 000 мм/с²** (Benchy ≈ 14 мин).
- **Шум:** от ~48–49 дБ (активное шумоподавление).
- **Рама:** **открытая**, без корпуса и нагреваемой камеры — ключевое ограничение по материалам (см. `04`).

## Умные функции (авто, на каждую печать)
- Полная авто‑калибровка: Z‑offset, авто‑выравнивание стола, компенсация вибраций/резонанса, давление сопла — без «бумажки».
- **Active Flow Rate Compensation**: высокочастотный вихретоковый датчик следит за давлением в сопле и держит поток ровным на высокой скорости.
- Калибровка потока и input shaping перед печатью.

## AMS
- Поддержка **одного AMS Lite** → до **4 цветов/материалов**. AMS Lite — открытая конструкция (без осушения, в отличие от закрытого AMS). RFID автоматически подтягивает профили филамента Bambu.

## Сеть и подключение
- **Только Wi‑Fi 2.4 ГГц** (нет Ethernet, нет 5 ГГц). Управление через **Bambu Studio** (десктоп) и **Bambu Handy** (моб.).
- **Cloud Mode (по умолчанию):** печать/мониторинг удалённо через облако Bambu; работает удалёнка в Handy; push‑to‑print из MakerWorld.
- **LAN Only Mode:** принтер общается только с устройствами в той же локальной сети, без облака.
  - Включение на экране: **Settings (шестерёнка) → General → «LAN Only Mode»**.
  - Там же показывается **Access Code** (hex‑строка) — пароль для Bambu Studio/сторонних тулов. Если он весь из нулей — выключи/включи LAN‑режим, чтобы перегенерировать.
  - **Серийный номер** виден на экране, в Bambu Studio и в Bambu Handy.
  - Минус: в чистом LAN Only удалённые функции Bambu Handy недоступны (Handy требует облако). Локальный мониторинг/печать в сети работают.
- **Локальный MQTT API** (им пользуются Home Assistant и подобные): IP принтера, **порт 8883 с TLS** (не открытый 1883), авторизация **access code + серийник**. Доступен в LAN/Developer Mode.

## Для нашего агента: LAN + Developer Mode
После прошивки янв‑2025 сторонний контроль (старт печати, движение, температуры, AMS, видео) закрыт «Authorization Control System». Чтобы MQTT/FTP остались открытыми **без авторизации**, нужен опциональный **LAN «Developer Mode»**.
- Включи: экран принтера → Settings → сеть/LAN → включить **LAN Mode** и **Developer Mode**.
- Это главная точка хрупкости: будущая прошивка может изменить правила. Закрепи прошивку и тестируй перед обновлением.
