# База знаний — 3D‑печать на Bambu Lab A1

Переиспользуемая справка для тебя и будущих агентов. Все числа — из официальных источников Bambu
(wiki, страницы магазина, TDS) и надёжных сообществ; там, где значение зависит от версии профиля,
это отмечено «проверить в своём Bambu Studio/Orca».

## Твоё оборудование
- Принтер: **Bambu Lab A1** (полноразмерный, не Mini)
- Филамент в наличии: **Bambu PETG HF White Matte** (высокотекучий, прочный, быстрый)

## С чего начать под конкретную печать
1. Высуши катушку (65 °C, 8 ч) — PETG чувствителен к влаге.
2. Возьми встроенный профиль **Bambu PETG HF** + процесс **A1 0.20 mm Quality**, примени оверрайды из `05`.
3. Один раз на катушку: **Flow Dynamics → Flow Ratio**, затем при желании Max Volumetric и тест ironing.
4. Для гладкого верха — включи ironing по значениям из `03`/`05`.
