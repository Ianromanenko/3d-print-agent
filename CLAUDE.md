# CLAUDE.md — инструкции для сессии в этом репозитории

Ты запущен в проекте **3D Print Agent** для принтера Bambu Lab A1.

## Если тебя просят что-то напечатать / смоделировать

**Прочитай `agent/BRAIN.md` и работай ровно по нему.** Это операционный промпт агента: пайплайн
понимание → **уточнение (блокирующее!)** → генерация CAD → ворота печатаемости → зрительный
само-чек ≥95% → слайсинг с профилем PETG HF → выдача `.gcode.3mf`.

Не начинай моделировать, пока пользователь не подтвердил, что ты правильно понял запрос —
это жёсткое правило проекта, а не вежливость.

Детерминированные стадии вызывай как инструменты через Bash:

```bash
.venv/bin/python -m agent.pipeline parse "<запрос>"    # черновик BuildSpec (правишь своим пониманием)
.venv/bin/python -m agent.pipeline verify spec.json    # генерация + gate + рендеры + рубрика
.venv/bin/python -m agent.pipeline spec spec.json      # generate → gate → slice
.venv/bin/python -m agent.pipeline ping                # доступность принтера
.venv/bin/python -m agent.pipeline send out.gcode.3mf  # заливка на A1 + старт печати
```

Визуальные слоты рубрики (`geometry`, `features`) приходят как `null` — **их заполняешь ты**,
открыв PNG-рендеры своим зрением. В этом смысл шага само-чека: детерминированный код меряет
bbox, а соответствие формы замыслу оцениваешь ты.

## Если тебя просят доработать код агента

- Архитектура и журнал стадий — `agent/ARCHITECTURE.md`; исходный план — `PLAN-3D-AGENT.md`.
- Знания о печати (параметры, ironing, филаменты, профиль PETG HF) — `knowledge/`.
- Тесты: `.venv/bin/python -m pytest tests/agent -v` — офлайн, принтер не нужен.

## Что НЕ надо «чинить»

- **Слайсер падает на Bambu Studio и уходит на OrcaSlicer** — это ожидаемое поведение
  (`agent/slice.py`). Причина внешняя: CLI Bambu Studio сегфолтится headless на macOS arm64
  (upstream #8569).
- **Python 3.12, а не системный** — под 3.14 нет колёс для CAD-стека (OCCT). Всегда работай
  через `.venv/bin/python`.
- `server/` и `web/` — **legacy** Node-визард из первой фазы. Он не поддерживается и к агенту
  отношения не имеет. Не трогай их, если об этом не попросили явно.

## Чего агент пока не умеет

Органика и фигурки (стадия 4b, Meshy) **не реализованы** — честно скажи об этом и предложи
механическую альтернативу, а не выдумывай обходной путь. Заливка на принтер (стадия 8) написана
и покрыта офлайн-тестами, но против живого A1 ни разу не гонялась.
