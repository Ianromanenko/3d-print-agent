# iPhone Action Button — вторичный триггер (на ходу)

Ссылка: `PLAN-3D-AGENT.md` §7, `blueprint/launch-setup.md` §B.
iPhone только **собирает ввод** и пробрасывает его на Mac по SSH — резать модель и
управлять принтером телефон физически не может (§1 плана). Вся тяжёлая часть — на Mac.

## Сборка Shortcut (приложение «Быстрые команды»)

Создай Shortcut из действий по порядку:

1. **Dictate Text** (голос → текст) *или* **Ask for Input** (набрать текст).
   Сохрани результат в переменную `Request`.
2. *(опц.)* **Take Photo** / **Select Photos** — если нужен фото-референс.
3. *(опц.)* **Record Audio** — если нужен сырой звук, а не только транскрипт.
4. *(опц., для фото/аудио)* **Base64 Encode** файла → передашь его в теле команды,
   либо предварительно залей по SCP и передай путь (см. ниже).
5. **Run Script Over SSH** со следующими полями:
   - **Host / Port**: IP Mac в локальной сети / 22
   - **User**: твой логин на Mac
   - **Authentication**: SSH-ключ (заведи ключ iPhone в `~/.ssh/authorized_keys` на Mac)
   - **Script**:
     ```sh
     $HOME/Claude/work/3d-print-agent/bin/print-agent "«Request»"
     ```
     (подставь переменную `Request` из шага 1 вместо `«Request»`)
6. Назначь Shortcut: **Настройки → Кнопка действия → Быстрая команда → этот Shortcut**.
   Дополнительно добавь его в **Пункт управления** и на экран «Домой».

## Передача фото/аудио

Два способа (детали — стадия 3, модуль `intake`):

- **Путь к файлу**: сначала действие **Run Script Over SSH** с `scp`-подобной заливкой,
  затем вызов `bin/print-agent --image /tmp/ref.jpg "…"`.
- **Base64 в аргументе**: закодировать вложение и передать; `intake` декодирует.

`bin/print-agent` уже принимает `--image <path>` и `--audio <path>` и прокидывает их
в пайплайн через `PRINT_AGENT_IMAGES` / `PRINT_AGENT_AUDIO`.

## Взаимодействие
- Уточняющие вопросы агента приходят **push-уведомлением** (канал — стадия 3).
- Готовое нарезанное задание появляется в **Bambu Handy** → там крутишь и жмёшь «Печать».

## Предпосылки на Mac
- Включить **Общий доступ → Удалённый вход (SSH)** в Системных настройках.
- Публичный ключ iPhone добавить в `~/.ssh/authorized_keys`.
- Mac и A1 — в одной Wi-Fi сети (A1 только 2.4 ГГц).
