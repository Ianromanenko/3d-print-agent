# Blueprint — Настройка триггеров запуска

Запуск **по требованию** (без демона). Основной — Raycast на Mac; вторичный — кнопка действия iPhone через SSH.

## A. Raycast‑хоткей (основной, Mac)
1. Установить **Raycast** (бесплатно).
2. Создать **Script Command** (Bash/Node), принимающий набранный текст как аргумент. Скелет:
   ```bash
   #!/bin/bash
   # @raycast.schemaVersion 1
   # @raycast.title 3D Print Agent
   # @raycast.mode fullOutput
   # @raycast.argument1 { "type": "text", "placeholder": "Что напечатать?" }
   REQUEST="$1"
   cd "$HOME/3d-print-agent" || exit 1
   # запустить интерактивную сессию агента с запросом (пример; подставит Fable 5):
   /usr/bin/env bash -lc "claude \"$REQUEST\""
   ```
3. Положить скрипт в папку Raycast Script Commands, назначить **глобальный хоткей**.
4. Использование: хоткей → печатаешь запрос → Enter → открывается интерактивная сессия (уточнения и результат сразу). Фото — передать путём к файлу/скриншоту в тексте запроса.

> Точную команду запуска агента подставит Fable 5 при сборке (Claude Code / Agent SDK entrypoint).

## B. iPhone — кнопка действия (вторичный, на ходу)
Собрать **Shortcut** из действий:
1. **Ask for Input** (текст) и/или **Dictate Text** (голос → текст).
2. (Опц.) **Record Audio** — если нужен сырой звук, не только транскрипт.
3. (Опц.) **Take Photo** / **Select Photos** — камера или медиатека.
4. **Run Script Over SSH** — зайти на Mac (host/IP, юзер, ключ) и запустить entrypoint агента, передав текст (и пути к загруженным файлам).
5. Назначить Shortcut на **кнопку действия** (Настройки → Кнопка действия → Быстрая команда). Дополнительно — в **Пункт управления** и на экран «Домой».

Взаимодействие: уточняющие вопросы приходят **push‑уведомлением**; готовое задание появляется в **Bambu Handy** — там смотришь и жмёшь «Печать».

> Для передачи фото/аудио: либо base64 в теле запроса, либо предварительная заливка файла на Mac по SCP/SSH и передача пути. Детали реализации — за Fable 5.

## C. Общее
- В начале каждой сессии агент делает **MQTT‑пинг A1** и предупреждает, если принтер выключен/недоступен.
- Ничего постоянно не висит: сессия живёт только на время запроса.

## Источники
- Apple Shortcuts: Ask for Input / Dictate Text / Record Audio / Take Photo / Select Photos / Run Script Over SSH; назначение на кнопку действия и Пункт управления; Raycast Script Commands.
