# Blueprint — Архитектура агента 3D‑печати

Агент — приложение на **Claude Agent SDK / Claude Code**, работающее на **Mac** в одной сети с A1.
Умная модель (**Fable 5**, иначе **Opus 4.8**) — на всех шагах, где нужен ризонинг; **сабагенты** — для дип‑ресёрча.
Запуск **по требованию** (без демона): каждый триггер поднимает свежую сессию.

## Пайплайн

```
ТРИГГЕР:
  • Mac:    Raycast‑хоткей → поле ввода → интерактивная сессия Claude Code в проекте
  • iPhone: Кнопка действия → Shortcut (текст + голос + фото) → SSH в Mac → старт сессии
      ▼
Сессия на Mac (сначала MQTT‑пинг A1; предупреждает, если принтер выключен)
  1. ПОНИМАНИЕ (умная модель, зрение): распознать голос, прочитать фото →
     структурная build‑spec: список объектов, размеры по каждому, механика/органика,
     кол‑во деталей, допуски, ограничения.
  2. УТОЧНЕНИЕ: пересказать понимание + точечные вопросы. БЛОК до подтверждения.
  3. ГЕНЕРАЦИЯ (гибридный роутер):
       • точное/механика → CadQuery/build123d (OCCT) или OpenSCAD+BOSL2 (шестерни).
         ОДИН STL НА ОБЪЕКТ, каждый со своими размерами.
       • органика/фигурка → Meshy text/image‑to‑3D → меш.
  4. ВОРОТА ПЕЧАТАЕМОСТИ: trimesh + manifold3d + pymeshlab — watertight И согласованность
     нормалей; авторемонт; регенерация если не чинится; слипшиеся тела разделить.
  5. САМОПРОВЕРКА (≥95 %): offscreen‑рендер каждого объекта с нескольких ракурсов →
     умная зрительная модель сверяет с запросом (+ фото): геометрия, пропорции, полнота фич;
     для механики — КОЛ‑ВО деталей, РАЗДЕЛЬНОСТЬ, замеренные размеры vs спека.
     <95 % → диагноз → правка CAD/регенерация → перерендер → переоценка. До порога/лимита.
  6. СЛАЙСИНГ (headless): Bambu Studio CLI, профиль A1 + PETG HF + процесс с оверрайдами (§6 плана).
     Все STL вместе + `--arrange 1` → раздельные объекты → output.gcode.3mf.
  7. ВЫДАЧА: FTP .gcode.3mf на A1 → задание видно в Bambu Handy → уведомление на телефон.
      ▼
Ты: Bambu Handy → крутишь/смотришь → «Печать».
```

## Обязательства ↔ требования
- **Раздельные объекты, не монолит:** один STL на деталь (генерация) + перепроверка кол‑ва/раздельности/размеров (самопроверка) + `--arrange 1` и «Split to Objects», никогда «Parts» (слайсинг).
- **≥95 % самопроверка:** зрительная рубрика + лимит итераций; агент сообщает финальную уверенность; не отдаёт деталь <95 % без пометки.
- **Уточнение до моделирования:** шаг 2 блокирует.
- **Умная модель + сабагенты:** понимание, CAD‑код, оценка — Fable 5/Opus 4.8; ресёрч — сабагенты.
- **PETG HF:** слайсинг всегда применяет профиль филамента.

## Модули (для реализации)
| Модуль | Ответственность | Ключевые тулзы |
|---|---|---|
| `intake` | текст/голос/фото → build‑spec | зрение модели, транскрипция |
| `clarify` | вопросы пользователю, блок до подтверждения | канал к телефону/чат |
| `generate/cad` | параметрический код точных деталей | CadQuery/build123d, OpenSCAD+BOSL2 |
| `generate/mesh` | органика через AI | Meshy API |
| `printability` | watertight/manifold/split | trimesh, manifold3d, pymeshlab, admesh |
| `verify` | рендер + зрительная оценка ≥95 % | offscreen render, зрение модели |
| `slice` | headless слайсинг + arrange | Bambu Studio CLI, JSON‑профили |
| `printer` | FTP‑загрузка + MQTT‑старт/статус + видимость в Handy | bambulabs-api / MQTT+FTP |
| `triggers` | Raycast + iPhone Shortcut запуск | Raycast script, Shortcuts + SSH |

## Рубрика самопроверки (пример весов)
- Геометрия/силуэт соответствует запросу — 35 %
- Пропорции/размеры (замер bbox vs спека) — 25 %
- Полнота фич (все запрошенные элементы есть) — 20 %
- Механика: кол‑во деталей + раздельность — 15 %
- Печатаемость (watertight/manifold пройдены) — 5 %
